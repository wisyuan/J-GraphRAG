\section{Replacement Experiments (RQ4)}
\label{sec:replacement}

\subsection{Protocol}
\label{sec:replacement:protocol}

\textbf{Replacement--retention}: we faithfully reimplement the non-LLM parts
of each framework (graph construction logic + retrieval algorithm) and swap
only the LLM extraction for the hybrid pipeline of \S\ref{sec:method:offline}.
The originals cannot be run locally (Fast-GraphRAG is broken), so we convert
via the archived leaderboard numbers plus a conversion factor:
\begin{align}
\text{retention} &= \mathrm{ACC}(\text{replaced}, \text{our judge}) \times \text{factor} \;/\; \text{leaderboard original},\\
\text{factor} &= \text{leaderboard RAG mean} \;/\; \text{our co-run B0}
\quad (\text{medical } 1.005,\ \text{novel } 0.885).
\end{align}
The verdict line is $\geq 0.9$. Evaluation: medical 56 questions (14 per level
$\times$ 4 levels) + novel 48 questions, DeepSeek judge (noise
$\pm 0.03$--$0.05$).

\subsection{Comparative analysis}

\textbf{dual-level is more stable than PPR on our graphs} (1.011/1.104 vs.\
0.996/0.881): MAX aggregation + naive interleaving is more robust to uneven
edge weights; PPR's global diffusion is highly sensitive to the passage/phrase
reset ratio. The production default is dual-level, with PPR as a tunable
option.
