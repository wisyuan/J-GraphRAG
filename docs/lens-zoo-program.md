# Lens Zoo 纲领：单 LLM 多透镜的功能区域制图与提取边界

> 版本：v0.1（2026-07-26）——seed 文档，角色同 `embedding-fractal-seed.md`
> 缘起：Phase 56/56b 证明 J-space ≠ 语义空间（闭环 FALSIFIED + 上下文边界假设 SUPPORTED），
> 由此产生两个更大的问题。本文档是第二篇论文（或 v1 会议扩展版）的候选框架。

## 1. 核心问题

- **Q1（功能区域可分离）**：单一 LLM 挂载不同透镜，能否判别出对文本进行不同处理的功能区域？判决要求 ≥3 个两两满足"功能验证 + 冗余审计"（§3）的区域。
- **Q2（提取边界）**：单一 LLM（多透镜）对语言各类信息的可提取性边界在哪里？产出 = 区域 × 信息类型的可提取性矩阵。v1 论文的能力地图（tech-report §5）是该矩阵的第一列。

## 2. 方法池与两段式协议

**不预设**任何方法发现的签名是什么。每种数学方法只是候选空间的生成器；每个生成空间走统一的两段式：

**第一段：均一性检验**——空间是否存在自洽结构（而不是噪声或方法伪影）。
判据按方法适配，例：
- 方差分解（SVD/PCA）：谱集中度与谱隙（top-k 方向解释的方差显著超随机矩阵基线）
- 聚类/流形：重采样稳定性（bootstrap 下簇分配 ARI > 0.5）
- 监督探针：跨上下文一致性（不同语料切片训练的探针方向 cosine > 0.7）
- 稀疏分解（pursuit/SAE 式）：重建稳定性 + 特征跨上下文复现率
- Jacobian 平均（J-lens）：已有先例（读出跨语料一致，原论文 + Phase 10-53）

**第二段：特征鉴定**——均一性成立的前提下，开放回答"这个结构是什么"：
用功能探针电池（检索 coverage / 言说准确率 / 风格判别 / 句法标注 / 关系判别…）
扫描该空间，**它预测什么它就是什么**——不预设对应关系，允许多功能、允许意外发现
（例：Phase 56 的 dense 空间预期是主题、实测是文体——这类错配本身就是发现）。

方法池（生成器，不含签名指派）：Jacobian 平均、方差分解、监督探针、蒸馏回归、
CKA/Procrustes（冗余裁判）、稀疏分解、图/张量谱。可按需扩充。

## 3. 判决标准（防循环性铁律）

区域认定是三级门，顺序不可颠倒：

1. **均一性**：空间有自洽结构（§2 第一段判据），否则只是噪声/伪影——不进入下一阶段。
2. **特征鉴定**：功能探针电池扫描，该空间在留出数据上显著预测某功能才算该区域的功能归属成立；指标预设、可证伪。
3. **冗余审计**：与已有区域 CKA 低、互相线性探针打不穿——否则只是同一区域的另一种看法。

蒸馏 lens 标星级：用 bge 监督"造"出来的空间均一性证明弱（结构是被强加的）；有效主张的形式是"多少维就够 + 与 J-space 的正交程度"。

## 4. 已有拼图（各 Phase 回填）

- workspace 区 ✓：概念/关系/角色/消歧提取有效（Phase 25/27/35/44）
- 文体区（半）：Phase 56 dense 空间被 boilerplate 主导——存在性线索，未做功能验证
- 语义区：不在 J-space（Phase 56 铁案）；位置未知（S1 的目标）
- 关系区 ✓：W² 多跳 0.998、CP 张量 0.81（Phase 45-47）
- 边界证据（Q2 已填格）：罕见专名 ✗ 结构性（52）、语料私有内容@查询侧 ✗ 上下文边界（56b）、cloze ✗ 四次（定律）

## 5. 分阶段计划

**S1 语义空间存在性探测（本机，~1h GPU）**：原始残差（不经 J 变换——路线 b 的 dense 是 transported 坐标，文体陷阱可能部分是坐标伪影）分层 mean-pool 编码 novel 4391 chunks + 48 queries，coverage 判决同 Phase 56 框架。预设：某层 ≥ bge−0.05 → 语义区存在并定位层；全层 < −0.10 → 7B 原始几何不足，语义区只能蒸馏/拟合构造。

**S2 区域刻画（CPU 为主）**：对 S1 候选层走两段式——SVD/探针生成候选子空间 → 均一性检验（谱隙/探针方向跨切片一致性）→ 功能电池鉴定（文体？主题？意外？不预设）；区域间 CKA/Procrustes 冗余审计。

**S3 语义 lens 构造**：①蒸馏 lens（残差→bge 最小二乘，8GB 可行）——主张形式为"维度需求 + 与 J-space 正交性"；②Jacobian 式语义 lens（语料平均 Jacobian → 同文档未来内容词）——最忠实的 J-lens 类比但需 backprop，放 4090 或 4b 缩小版。

**S4 成稿**：Q2 矩阵完整化 + 与 v1 能力地图合并 → 第二篇论文（暂名 "Lens Zoo: Functional Cartography of a Single LLM and the Boundary of Zero-Generation Extraction"）。

## 6. 与既有工作的关系

- **v1 论文（J-GraphRAG）**：本纲领不推翻 v1；v1 的能力地图是 Q2 矩阵第一列，negative results 是边界线的第一批点。
- **J-Space 原论文**：提供了第一个透镜（J-lens）与层带结构先例（前 1/3 噪声、workspace 带、motor 带）；selectivity 与 6-10% 方差份额是本纲领的重要先验（workspace 注定不是全部）。
- **embedding-fractal 渊源（Phase 1-9）**：本仓库的起点就是嵌入几何研究，Lens Zoo 是这条线的回归与升级。
- **LLM2Vec / Echo / SAE 文献**：LLM 残差确有可用几何（需脚手架/微调）——S1 的无训练基线是其中最简单的形态。

## 7. 风险

- 多重比较：方法够多总能"发现"东西——§3 铁律是唯一防线，每个区域必须功能验证。
- 7B 规模限制：语义几何可能本来就弱（bge 是专门训练的），S1 全灭也是干净答案（语义区不可无训练读取）。
- 单模型：所有结论限 Qwen2.5-7B；跨模型（Phase 57/58）是泛化性的前提。
